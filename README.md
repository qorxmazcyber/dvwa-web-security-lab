DVWA Web Security Lab
# Overview
This project is a hands-on web application security lab built using Damn Vulnerable Web Application (DVWA).
The goal is to understand common web application vulnerabilities, practice security testing techniques, and document findings in a controlled laboratory environment.
# Objectives
* Understand common web application vulnerabilities.
* Learn the fundamentals of web security testing.
* Practice identifying and analyzing security weaknesses.
* Understand how vulnerabilities can affect web applications.
* Explore mitigation techniques and secure coding practices.
* Document practical cybersecurity exercises and findings.

# Lab Environment
The following technologies are used or planned for this laboratory:
* Kali Linux
* DVWA (Damn Vulnerable Web Application)
* Apache HTTP Server
* PHP
* MySQL or MariaDB
* VirtualBox
*The final environment and versions will be documented after verification.*
# Topics to Explore
* SQL Injection (SQLi)
* Cross-Site Scripting (XSS)
* Command Injection
* File Inclusion
* File Upload Security
* Authentication and Session Management
* Input Validation and Output Encoding
# Methodology
1. Configure the laboratory environment.
2. Verify that DVWA is running correctly.
3. Study each vulnerability in an isolated environment.
4. Perform controlled security tests.
5. Record observations and results.
6. Document possible mitigations and secure coding practices.
